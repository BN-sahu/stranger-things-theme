An immersive, animated frontend web application inspired by the Upside Down. Built to showcase modern UI/UX interactions, complex animations, and 3D CSS rendering.

**🌌 [Enter the Upside Down (Live Demo)](https://stranger-things-theme.netlify.app/)**

## ✨ Features
* **Flashlight Reveal Effect:** Custom CSS masking and mouse tracking to reveal monsters hidden in the dark.
* **Parallax Scrolling:** Disconnected scroll speeds between the background and foreground elements to create unsettling depth.
* **3D Holographic Cards:** Interactive character grid utilizing framer-motion and CSS perspective to tilt elements in 3D space based on cursor coordinates.
* **Draggable Isometric Map:** A tabletop-style 3D map of Hawkins that users can grab and explore.
* **Atmospheric Details:** Features a custom glowing spore cursor, drifting 3D dust particles, and flickering neon typography.

## 🛠️ Tech Stack
* **Framework:** React 19[cite: 5]
* **Build Tool:** Vite 7[cite: 5]
* **Animations:** Framer Motion 12[cite: 5]
* **Styling:** Pure CSS with CSS Variables and 3D Transforms
